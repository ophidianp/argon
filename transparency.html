How Argon was made.

Straight answers about who wrote the code and what happens to your data.

  • The code: built with AI. Argon and this website were written with Claude, an AI model, directed and tested by Pavan. The design follows the same style as Chlorine and the other sites in this family. The whole conversation is below.
  • Your data: stays on your PC. Argon has no servers, accounts or telemetry. Boards, notes, memory and settings are JSON files in your app data folder, with rolling backups.
  • Your accounts: never touched. Agents sign in by themselves. Argon only checks whether each agent has saved a login file, to show "signed in" in the setup panel. It never reads or sends what's inside.
  • Usage stats: read locally. The usage chart reads Claude Code and Codex session logs already on your PC and adds up token counts. Nothing leaves your machine.
  • Safety: approvals stay on. Agents ask before editing files or running commands. Auto-approve is off by default and comes with a warning if you turn it on.

The conversation itself.

From the first message of the Claude Code session Argon was made in to the request for this page. Only what was said in the chat is shown. Tool use is left out, and file paths, local addresses, emails and keys are masked. It reads like a messaging app, but you can't reply.
