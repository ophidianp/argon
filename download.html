Before you start

Installing agents.

How do I install Claude Code?

In Argon, open Agents setup and press Install next to Claude Code, or run npm install -g @anthropic-ai/claude-code yourself. Open a Claude Code tile and it will ask you to sign in with your Claude plan or a Console account.

How about Codex and Gemini CLI?

Same idea: npm install -g @openai/codex signs in with ChatGPT, and npm install -g @google/gemini-cli signs in with a Google account. Argon's setup panel can run these for you.

npm isn't recognised. What now?

Install Node.js, then open a new terminal so Windows picks up the new path. Argon re-reads the path every time it opens a terminal, so new tools work there straight away.
