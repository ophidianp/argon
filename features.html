Features

Everything on one board.

A tour of what Argon does, from the board itself to the small touches that make running many agents feel calm.

  • The board
  • Agents and status
  • Orchestration
  • Tiles

01 · The board

Room for everything.

Infinite canvas

Zoom with the wheel, scroll the board with Ctrl + wheel, drag with the middle button to pan, and fit everything with Ctrl 0.

Workspaces as tabs

Each project folder gets its own board. Switch with Ctrl 1–9; agents keep running in the background.

Ink and images

Draw over the board to sketch ideas, and drop or paste screenshots straight onto it.

The Add selector

Hover the Add button in the toolbar for a floating glass selector: a shell console, a picture, or a folder to connect to the project.

Fly to anything

Click an agent in the mission map or double-click a tile header to glide to it at full size.

02 · Agents and status

Real terminals. Live status.

12 agents built in

Claude Code, Codex, Gemini CLI, Copilot CLI, OpenCode, Qwen Code, Amp, Aider, Cursor CLI, Goose, Crush and a plain terminal, plus any custom command.

Working, resting, needs you

Every tile shows its state. Approval prompts turn it amber and float it to the top of the mission map.

Agents setup

See which agents are installed and signed in, and install missing ones in one click.

Pictures in consoles

Paste, drop or pick a screenshot into a console. Claude Code and Codex get it as an attached image, and the console shows it, in the terminal or in the conversation.

Account profiles

Run Claude Code or Codex under a second account. Each profile keeps its own sign-in, so you can spread work across plans.

Safe by default. Auto-approve flags are off unless you turn them on in Settings, with a clear warning first.

03 · Orchestration

Direct the team, not each tab.

Command bar

Press Ctrl K and type. Send to @claude-1, a team like #frontend, or @all, or run commands like /spawn codex 3.

Composer

Line up to 12 agents with their first prompts and launch them together in a neat grid.

Loops

Re-send a prompt whenever an agent goes idle or on a schedule, and stop automatically when a goal phrase appears.

Handoffs

One agent writes a brief into .argon/handoffs/, the next one is told to read it and carry on.

Groups

Tag consoles with a team name to order them together and see them grouped in the mission map.

Orchestrator

Give orders to several agents at once. Its text box grows as you write, and you can start typing anywhere on it.

Project memory

Global and per-repo notes that you push into consoles when you want agents to know them.

04 · Tiles

Plan right next to the work.

Notes, checklists, kanban

Sticky notes in five colours, checklists with progress, and a drag-and-drop kanban board.

Calendar

A month view for deadlines and release days, right on the board.

Web preview

A live view of your localhost dev server, with the web inspector one click away.

Files and git

Browse and preview files with highlighting, and commit, pull, push or switch branches from a git card.

05 · Make it yours

Your colours. Your feel.

Accent colour

Presets from the default Ember to lavender, rose, mint and sky, or any colour you like. The taskbar icon takes it on too.

Looks and glass

Ember by default, plus Midnight, Abyss, Dusk, Slate and looks styled after each agent; Paper and Daylight by day. Liquid glass everywhere, and Windows Mica or Acrylic behind the window.

Board background

Dots, grid lines, a slowly drifting aurora, or plain.

Terminal and motion

Choose the terminal font and cursor, corner style, and switch animations off for a stiller feel. Argon also greets you by name.

06 · Continuity and privacy

Yours, on your PC.

Resume after restart

Consoles relaunch in place and continue their last session where the agent supports it.

Autosave with backups

Every board is saved as you work, with rolling backups in your data folder.

Plan limits and usage

How much of your Claude, Codex and Copilot plan is left and when it resets, plus token charts read from logs on your PC.

Automatic updates

Settings → Updates: ask first, or download quietly and install when you close Argon. Every update is signed, and Argon checks the signature before it installs anything.

No Argon servers

No account, no telemetry. Sign-in checks only look for whether each agent has saved a login file.
