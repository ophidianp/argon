Features

Everything on one board.

A tour of what Argon does, from the board itself to the small touches that make running many agents feel calm.

The board Agents and status Orchestration Tiles Make it yours Continuity and privacy
01

The board

Room for everything.

Infinite canvasZoom with the wheel, scroll the board with Ctrl + wheel, drag with the middle button to pan, and fit everything with Ctrl 0.
Workspaces as tabsEach project folder gets its own board. Switch with Ctrl 1–9; agents keep running in the background.
Ink and imagesDraw over the board to sketch ideas, and drop or paste screenshots straight onto it.
The Add selectorHover the Add button in the toolbar for a floating glass selector: a shell console, a picture, or a folder to connect to the project.
Fly to anythingClick an agent in the mission map or double-click a tile header to glide to it at full size.
02

Agents and status

Real terminals. Live status.

12 agents built inClaude Code, Codex, Gemini CLI, Copilot CLI, OpenCode, Qwen Code, Amp, Aider, Cursor CLI, Goose, Crush and a plain terminal, plus any custom command.
Working, resting, needs youEvery tile shows its state. Approval prompts turn it amber and float it to the top of the mission map.
Agents setupSee which agents are installed and signed in, and install missing ones in one click.
Pictures in consolesPaste, drop or pick a screenshot into a console. Claude Code and Codex get it as an attached image, and the console shows it, in the terminal or in the conversation.
Account profilesRun Claude Code or Codex under a second account. Each profile keeps its own sign-in, so you can spread work across plans.

Safe by default. Auto-approve flags are off unless you turn them on in Settings, with a clear warning first.

03

Orchestration

Direct the team, not each tab.

Command barPress Ctrl K and type. Send to @claude-1, a team like #frontend, or @all, or run commands like /spawn codex 3.
ComposerLine up to 12 agents with their first prompts and launch them together in a neat grid.
LoopsRe-send a prompt whenever an agent goes idle or on a schedule, and stop automatically when a goal phrase appears.
HandoffsOne agent writes a brief into .argon/handoffs/, the next one is told to read it and carry on.
GroupsTag consoles with a team name to order them together and see them grouped in the mission map.
OrchestratorGive orders to several agents at once. Its text box grows as you write, and you can start typing anywhere on it.
Project memoryGlobal and per-repo notes that you push into consoles when you want agents to know them.
04

Tiles

Plan right next to the work.

Notes, checklists, kanbanSticky notes in five colours, checklists with progress, and a drag-and-drop kanban board.
CalendarA month view for deadlines and release days, right on the board.
Web previewA live view of your localhost dev server, with the web inspector one click away.
Files and gitBrowse and preview files with highlighting, and commit, pull, push or switch branches from a git card.
05

Make it yours

Your colours. Your feel.

Accent colourPresets from the default Ember to lavender, rose, mint and sky, or any colour you like. The taskbar icon takes it on too.
Looks and glassEmber by default, plus Midnight, Abyss, Dusk, Slate and looks styled after each agent; Paper and Daylight by day. Liquid glass everywhere, and Windows Mica or Acrylic behind the window.
Board backgroundDots, grid lines, a slowly drifting aurora, or plain.
Terminal and motionChoose the terminal font and cursor, corner style, and switch animations off for a stiller feel. Argon also greets you by name.
06

Continuity and privacy

Yours, on your PC.

Resume after restartConsoles relaunch in place and continue their last session where the agent supports it.
Autosave with backupsEvery board is saved as you work, with rolling backups in your data folder.
Plan limits and usageHow much of your Claude, Codex and Copilot plan is left and when it resets, plus token charts read from logs on your PC.
Automatic updatesSettings → Updates: ask first, or download quietly and install when you close Argon. Every update is signed, and Argon checks the signature before it installs anything.
No Argon serversNo account, no telemetry. Sign-in checks only look for whether each agent has saved a login file.
